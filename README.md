## Our Project

Our project is an autonomous Sumo Robot.

The robot will search for the opponent and try to push it outside the ring.

The robot will also use sensors to detect the white line and stay inside the ring.

## Our Robot

We are planning to use:

- 4 DC motors
- 4 wheels
- Teensy 4.0
- Motor drivers
- Distance sensors
- Line sensors
- Battery

We will design and build the chassis ourselves.

## Our Work

During this project, we will:

1. Design the robot.
2. Build the chassis.
3. Connect the electronics.
4. Program the robot.
5. Test the sensors and motors.
6. Test different Sumo strategies.
7. Improve the robot after every test.

We will use this GitHub repository to save our code, designs, photos, tests, and project progress.
